# NIFTy.re adapter

`spectracles.nifty` connects a `Posterior` to [NIFTy.re](https://ift.pages.mpcdf.de/nifty/)
for MGVI and geoVI. It needs the optional dependency: `pip install "spectracles[nifty]"`.
Importing the module doesn't import NIFTy; only `to_nifty` does.
