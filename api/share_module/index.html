    ShareModule¶

    ShareModule is a wrapper around JAX/Equinox models that enables parameter sharing and provides utilities for model inspection and manipulation.

    Building Models¶

    Use build_model() to construct your Equinox model and wrap it in a ShareModule. Pass the model class followed by its constructor arguments:

    import spectracles as sp

# Equivalent to wrapping MyModel(shared_component=inner, ...)
model = sp.build_model(MyModel, shared_component=inner, ...)

    Inspecting the Model¶

    Parameter Paths¶

    # Get all unique parameter paths (excludes shared duplicates and Known)
paths = model.get_parameter_paths()

# Include shared parameters
paths = model.get_parameter_paths(show_shared=True)

# Include Known parameters
paths = model.get_parameter_paths(show_knowns=True)

    Parameter Summary¶

    # Print a rich table of all parameters
model.get_parameter_summary()

    Shows path, shape, bounds, free/fixed status, and sharing info for each parameter.

    Sharing Summary¶

    # Component-level: which modules are the same object
model.get_sharing_summary(level="component")
# Returns: {'line_1.v': ['line_2.v']}

# Parameter-level: which parameter values are shared
model.get_sharing_summary(level="parameter")
# Returns: {'line_1.v.coefficients': ['line_2.v.coefficients']}

    Model Tree¶

    # Print the model structure
model.print_model_tree()

# Include sharing relationships
model.print_model_tree(show_sharing=True)

    Model Graph¶

    # Plot the model as a directed graph
model.plot_model_graph()

# Component-level view (shared modules point to same node)
model.plot_model_graph(sharing_level="component")

# Parameter-level view (shows all paths)
model.plot_model_graph(sharing_level="parameter")

    Modifying Parameters¶

    Setting Values¶

    # Set a single parameter
model = model.set("line_1.A.coefficients", new_value)

# Set multiple parameters
model = model.set(
    ["path.to.param1", "path.to.param2"],
    [value1, value2]
)

    Fixing/Freeing Parameters¶

    # Fix parameters (won't be optimized)
model = model.set_fixed_status(["path.to.param"], [True])

# Free parameters
model = model.set_fixed_status(["path.to.param"], [False])

# Fix all parameters
model = model.fix_all()

# Free all parameters
model = model.free_all()

    Validation¶

    # Check sharing structure is valid
info = model.validate_sharing()

    get_parameter_paths(show_shared=False, show_knowns=False) ¶

    Get all parameter paths that can be used with the set() method.

    Parameters:

    Name Type Description Default
    show_shared bool

    If False (default), only returns paths to unique/parent parameters. If True, also includes paths to shared (duplicate) parameters.

    		 False
    show_knowns bool

    If False (default), excludes Known parameters from the results. Known parameters are fixed constants that cannot be optimized.

    		 False

    Returns:

    Type Description
    list[str]

    A list of parameter path strings (e.g., ['line.A.coefficients',
    list[str]

    'line.v.coefficients']).

    Examples:

    >>> model.get_parameter_paths()
['line_1.A.coefficients', 'line_1.v.coefficients', 'line_2.A.coefficients']
>>> model.get_parameter_paths(show_shared=True)
['line_1.A.coefficients', 'line_1.v.coefficients', 'line_2.A.coefficients',
 'line_2.v.coefficients']  # line_2.v is shared with line_1.v

    get_parameter_summary(show_shared=True, show_knowns=False) ¶

    Print a summary table of all parameters with their status.

    Shows path, shape, bounds, free/fixed status, and sharing info.

    Parameters:

    Name Type Description Default
    show_shared bool

    If True (default), include parameters that are shared from other parameters. If False, only show unique/parent parameters.

    		 True
    show_knowns bool

    If False (default), exclude Known parameters from the summary. If True, include them with status 'known'.

    		 False

    Examples:

    >>> model.get_parameter_summary()
Parameter Summary
──────────────────────────────────────────────────────────────────
Path                      Shape     Bounds       Status  Shared from
──────────────────────────────────────────────────────────────────
line_1.A.coefficients     (10,)     (-∞, ∞)      free    -
line_1.v.coefficients     (10,)     (-∞, ∞)      fixed   -
line_2.v.coefficients     (10,)     (-∞, ∞)      fixed   line_1.v.coefficients
──────────────────────────────────────────────────────────────────
3 parameters (2 unique, 1 shared) · 1 free, 2 fixed

    get_sharing_summary(level='component') ¶

    Get a summary of what is shared in the model.

    Parameters:

    Name Type Description Default
    level str

    What level of sharing to report: - 'component': Shows which modules are the same object. (e.g., 'line_1.v' -> ['line_2.v']) - 'parameter': Shows which leaf parameter arrays are shared. More comprehensive, catches sharing done via tree_at. (e.g., 'line_1.v' -> ['line_2.v'])

    		 'component'

    Returns:

    Type Description
    dict[str, list[str]]

    A dictionary mapping parent paths to lists of paths that share
    dict[str, list[str]]

    with them. Only items that are actually shared are included.

    Examples:

    >>> model.get_sharing_summary()
{'line_1.v': ['line_2.v']}

    print_model_tree(show_sharing=False) ¶

    Print the model tree in an easy to parse format.

    Parameters:

    Name Type Description Default
    show_sharing bool

    If True, also print summaries of sharing relationships after the tree. Shows both shared modules (entire modules that are the same object) and shared parameters. Default is False for backwards compatibility.

    		 False

    Example with show_sharing=True: └── model (LineRatioModel) ├── line_1 (EmissionLine) │ └── v (GPField) └── line_2 (LinkedEmissionLine) └── v (GPField)

    Shared modules (parameters within are also shared):
  line_1.v:
    ← line_2.v

Shared parameters:
  line_1.v.coefficients:
    ← line_2.v.coefficients

    Parameters:

    Name Type Description Default

    		 required
    values list[Array]

    List of new values for each parameter.

    		 required
    allow_set_knowns bool

    set_fixed_status(params, fix) ¶

    Return a new model with parameters updated to be fixed or not based on provided paths and list of bools. Can only be used to update fixed statuses of Parameters or ConstrainedParameters. The model must not be locked.

    Known parameters cannot be unfixed - they are always fixed by definition.

    fix_all() ¶

    Return a new model with all parameters set to fixed.

    This is useful for freezing all parameters, e.g., when you want to use the model for inference only without any further optimization.

    Returns:

    Type Description
    Self

    A new ShareModule with all parameters fixed.

    Examples:

    >>> model = build_model(MyModel, ...)
>>> frozen_model = model.fix_all()
>>> # All parameters are now fixed

    free_all() ¶

    Return a new model with all parameters set to free (not fixed).

    This is useful for unfreezing all parameters for optimization.

    Returns:

    Type Description
    Self

    A new ShareModule with all parameters free.

    Examples:

    >>> frozen_model = model.fix_all()
>>> unfrozen_model = frozen_model.free_all()
>>> # All parameters are now free

    validate_sharing(raise_on_error=True) ¶

    Validate the sharing structure of the model.

    Checks that: 1. All Shared objects reference valid parent parameters 2. Parent parameters exist and have the expected shape 3. No orphaned Shared objects exist

    Parameters:

    Name Type Description Default
    raise_on_error bool

    If True (default), raises ValueError on validation failure. If False, returns validation results without raising.

    		 True

    Returns:

    Type Description
    dict[str, Any]

    A dictionary containing validation results:
    dict[str, Any]
    • 'valid': bool - True if all checks passed
    dict[str, Any]
    • 'n_shared_params': int - Number of shared parameter relationships
    dict[str, Any]
    • 'n_unique_params': int - Number of unique parameters
    dict[str, Any]
    • 'errors': list[str] - List of error messages (empty if valid)

    Examples:

    >>> result = model.validate_sharing(raise_on_error=False)
>>> if not result['valid']:
...     print("Errors:", result['errors'])

    copy() ¶

    Create a proper copy of the ShareModule with correct sharing structure preserved and duplicated array data. It's like deepcopy but preserves the sharing structure.

    get_locked_model() ¶

    Get a locked model. Locked models do not properly track shared parameters and so can no longer be optimised. Since all model parameters contained their actual values instead of some containing Shared objects, any subcomponent of the model may be called to make predictions, which is the primary use case for a locked model. You can't convert a locked model back, but this function returns a copy anyway so it doesn't matter.
