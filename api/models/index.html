    Model Components¶

    Building blocks for spectrospatial models. Combine them inside your own Equinox module and wrap it with build_model.

    Kernels¶

    Kernels define the power spectrum of a FourierGP. A subclass only needs to implement feature_weights(freqs), returning sqrt(P(k)) on the mode grid.

    spectracles.Kernel ¶

    Bases: Module

    Base class for kernels. Subclasses declare whatever hyperparameter fields they need. The only contract is feature_weights(freqs) -> sqrt(P(k)) on the mode grid.

    spectracles.model.kernels.LogLogLinear ¶

    Bases: Kernel

    Log-log-linear CFM kernel: log-amplitude PSD is linear in log(k).

    feature_weights(freqs) = exp(m_0 + m_s * log(k)) with DC (k=0) forced to zero so the fluctuation field has zero mean by construction. The field's spatial mean should be provided separately via FourierGP.zeromode.

    m_s is the spectral index; m_0 the log-amplitude. For negative m_s (the physically common regime) the continuous PSD is IR-divergent, which is why the DC term must be handled as a separate Parameter outside the PSD.

    spectracles.model.spatial.FourierBasis ¶

    Bases: SpatialModel

    A spatial model using a fixed Fourier basis with learnable coefficients.

    Note that this is different to a FourierGP, which uses a kernel to regularise the coefficients.

    spectracles.model.spatial.MultiFourierGP ¶

    Bases: SpatialModel

    A collection of independent FourierGPs grouped to better batch through fiNUFFT calls. Requires that all component GPs use the same number of modes, but can use different kernels.

    Very much a work in progress.
