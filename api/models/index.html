    Model Components¶

    Building blocks for spectrospatial models. Combine them inside your own Equinox module and wrap it with build_model.

    Parameters¶

    spectracles.Parameter ¶

    Bases: Module

    A parameter in a statistical model, which may be fixed or free, and may have a prior.

    A free parameter is inferred (and needs a prior for that). A fixed one (fixed=True) keeps its value, but can be freed again, e.g. by set_fixed_status or a schedule. For constants that should never be freed, use Known.

    The prior is a static field: it is part of the model's structure, not an array leaf, so it is never optimised and never mistaken for a shared array.

    debug_repr() ¶

    Return the full equinox-style repr for debugging.

    spectracles.ConstrainedParameter ¶

    Bases: Module

    A parameter in a statistical model, which may be fixed or free, with lower and/or upper bounds. Can be an array, but all entries must share the same bounds.

    debug_repr() ¶

    Return the full equinox-style repr for debugging.

    spectracles.Known ¶

    Bases: Parameter

    A constant of the problem, such as a rest wavelength: never inferred or optimised.

    Unlike a fixed Parameter, it can never be freed, it is left out of parameter summaries and path listings by default (show_knowns=True), and set refuses to change it unless given allow_set_knowns=True.

    Kernels¶

    Kernels define the power spectrum of a FourierGP. A subclass only needs to implement feature_weights(freqs), returning sqrt(P(k)) on the mode grid.

    spectracles.Kernel ¶

    Bases: Module

    Base class for kernels. Subclasses declare whatever hyperparameter fields they need. The only contract is feature_weights(freqs) -> sqrt(P(k)) on the mode grid.

    Kernels can also give their continuous form, which the discretisation diagnostic compares the field against: spectral_density(k), the 2D spectral density normalised so that its integral over k is the variance, and covariance(r). Both raise NotImplementedError unless a kernel defines them.

    spectral_density(k) ¶

    The 2D spectral density S(|k|), with integral over k equal to k(0).

    covariance(r) ¶

    The covariance k(r) at separation r.

    spectracles.model.kernels.LogLogLinear ¶

    Bases: Kernel

    Log-log-linear CFM kernel: log-amplitude PSD is linear in log(k).

    feature_weights(freqs) = exp(m_0 + m_s * log(k)) with DC (k=0) forced to zero so the fluctuation field has zero mean by construction. The field's spatial mean should be provided separately via FourierGP(..., mean=...).

    m_s is the spectral index; m_0 the log-amplitude. For negative m_s (the physically common regime) the continuous PSD is IR-divergent, which is why the DC term must be handled as a separate Parameter outside the PSD.

    spectracles.Domain dataclass ¶

    The square region the data cover, in the data's own units (e.g. arcsec).

    A FourierGP given a domain works in those units: its length scale is in the same units as the coordinates, and it represents the field on a periodic box made of the domain plus a margin of padding on each side. Several GPs can share one domain and still choose their own padding.

    spectracles.FourierGP ¶

    Bases: SpatialModel

    A Gaussian-process field, represented by Fourier modes on a periodic box.

    With a domain, coordinates and length scales are in the domain's units (e.g. arcsec), and the field lives on a periodic box of the domain plus padding × extent on each side. The modes and padding are then chosen for you, so that the field matches its kernel to tol over the range of length scales it can take (by default, its prior's 1% to 99% quantiles):

    FourierGP(kernel, domain=domain)
FourierGP(kernel, domain=domain, tol=1e-4, length_scale=(30.0, 300.0))
FourierGP(kernel, domain=domain, n_modes=(301, 301), padding=0.15)  # by hand

    Without a domain, coordinates must already lie in [-π, π], the length scale is in those units, and n_modes is needed.

    A field can have a mean, a Parameter added to the GP, and a link that transforms the result, e.g. for a positive line flux:

    FourierGP(kernel, domain=domain, mean=Parameter(prior=Normal(0.0, 1.0)), link="exp")

    With a mean, the GP's own constant (k = 0) mode is dropped, so the mean alone sets the field's average over the box; the kernel's variance is still the field's pointwise variance.

    spectracles.FieldFromRatio ¶

    Bases: SpatialModel

    A field given as a base field times a ratio: base(x) × 10^log10_ratio(x).

    Useful when a line's ratio to another line is the quantity of interest, e.g. [N II]/Hα. The ratio is modelled through its base-10 log, so it is positive; give log10_ratio a mean to set the typical ratio:

    halpha = FourierGP(k1, domain=d, mean=Parameter(prior=Normal(0, 1)), link="exp")
log10_ratio = FourierGP(k2, domain=d, mean=Parameter(prior=Normal(-0.5, 0.5)))
nii = FieldFromRatio(base=halpha, log10_ratio=log10_ratio)

    Name Type Description Default

    		 required
    log10_ratio SpatialModel

    		 required

    spectracles.model.spatial.FourierBasis ¶

    Bases: SpatialModel

    A spatial model using a fixed Fourier basis with learnable coefficients.

    Note that this is different to a FourierGP, which uses a kernel to regularise the coefficients.

    spectracles.model.spatial.MultiFourierGP ¶

    Bases: SpatialModel

    A collection of independent FourierGPs grouped to better batch through fiNUFFT calls. Requires that all component GPs use the same number of modes, but can use different kernels.

    Not available yet: instantiating it raises NotImplementedError. It holds its kernels in a list, which built models will support from 1.1. The aim is faster models with several fields on GPU, since such fields usually share one frequency grid and can go through one batched NUFFT.

    Data¶

    SpatialData is the base class for the points a spatial model is evaluated at. Subclass it to carry extra per-point fields your models need.

    spectracles.SpatialData ¶

    Bases: Module

    Base class for the spatial data that spatial models are evaluated at.

    Subclasses must provide x, y (sky coordinates in model units) and idx (each point's index, e.g. its spaxel), all flat arrays. Declare them with field(converter=convert_to_flat_array) to flatten inputs, and add any other per-point fields a model needs:

    class MySpatialData(SpatialData):
    x: Array = field(converter=convert_to_flat_array)
    y: Array = field(converter=convert_to_flat_array)
    idx: Array = field(converter=convert_to_flat_array)
    exposure_idx: Array = field(converter=convert_to_flat_array)
